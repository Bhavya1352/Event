# HappyHearts

HappyHearts is an event decoration website where users can explore decoration services and book events online. It is designed with a clean, responsive interface for a smooth browsing experience.

## Features

* Browse event decoration services
* Online booking form
* Service gallery
* Responsive design
* Smooth animations

## Tech Stack

* React
* TypeScript
* Tailwind CSS
* Vite
* Radix UI
* Lucide React

## Run Locally

```bash
git clone https://github.com/Bhavya1352/Event.git
cd Event
npm install
npm run dev
```

Open **http://localhost:8080** in your browser.

## Build

```bash
npm run build
```
